# Figure manifest

Maps every panel in the article to the exact script that generates it. Folder
names below are content-based (`genotype_validation`, not `Figure1`), so a
future renumbering of the manuscript's figures only means editing this table
— no files move, nothing needs re-running.

Where a panel has no generating script (a photograph, a Sanger trace, a
hand-drawn schematic, an externally supplied table), it's listed as a static
asset, not a pipeline output.

## Notes

- The tornado plot's background-region panel is generated by
  `scripts/publication_figures/tornado/03_define_background_regions.R`
  (consensus ATAC peaks with no TOBIAS footprint, fixed-seed sampling) — see
  that script's header for the exact method.
- `scripts/publication_figures/tornado/02_define_bound_highconf_canon.sh`
  expects `all_WT_bound_highconf.bed` as an input; see the script header for
  what it needs and where to source or regenerate it.
- Every ATAC differential-accessibility result in this repo uses the loess
  normalization arm (`scripts/atac/A04b_Csaw_Loess_Norm.R`), the one reported
  in the paper — see `docs/A04b_normalization_methodology.md` for the full
  comparison against the alternative that was evaluated.
- TF binding calls use TOBIAS's own binding-significance flag; see
  `scripts/atac/A07b_TOBIAS_DOWNSTREAM.R` for the comparison against the
  alternative method that was evaluated.
- The TF regulatory network is CollecTRI-based; see `docs/decisions.md` for
  the network-inference method that was evaluated and not used.
